### CLI vs EXPO
**---------------------- CLI -------------------------**

*Command Line Interface*
- Requires manual setup with Android studio/Xcode
- Slower to start due to setup.
- Full access to native code.
- Manual build and deployment
- Smaller app size.

**---------------------- Expo -------------------------**
- Easy setup with minimal configuration
- Faster to start, beginner-friendly
- Limited access without ejecting
- Simplified build process
- Larger app size due to extra dependencies
